status-bar

Chỉ báo Claude Code, thời tiết, crypto và phần cứng trên thanh trạng thái Ubuntu/GNOME. Đây là apt repository — xem mã nguồn tại github.com/minhngoc2512/status-bar.

Cài đặt

curl -fsSL @BASE_URL@/status-bar-archive-keyring.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/status-bar-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/status-bar-archive-keyring.gpg] @BASE_URL@/ ./" \
  | sudo tee /etc/apt/sources.list.d/status-bar.list

sudo apt update
sudo apt install status-bar

Sau khi cài

claude-status-hooks                  # chạy bằng user thường, KHÔNG dùng sudo
systemctl --user start claude-status

Cập nhật

sudo apt update && sudo apt upgrade

Gỡ

sudo apt remove status-bar
sudo rm /etc/apt/sources.list.d/status-bar.list \
        /usr/share/keyrings/status-bar-archive-keyring.gpg
Gói Architecture: all. Cần Ubuntu 20.04 trở lên (hoặc bản phân phối tương đương) với GTK 3, PyGObject và extension AppIndicator.
